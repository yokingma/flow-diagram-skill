# 交付质量按必需检查范围汇总

Status: accepted

来源：FlowSVG [`86bb7ad`](https://github.com/yokingma/FlowSVG/blob/86bb7ad29484d7deb63142c1df84c6944a7c0eb4/docs/adr/0011-delivery-quality-follows-required-checks.md)。本仓保留与 Skill 有关的决策和职责边界。

本设计已在 2026-10-29 的访谈中得到逐项及整体确认，并已在集成分支 `codex/flowsvg-skill-authoring-efficiency` 中实施。票据 01–05 已解决。

图解的交付完成只表示请求文件已齐备；交付质量按本次交付所需的检查范围汇总，不能仅凭全部预览已复核就认定正式图片或实际 HTML 已检查。这样可以避免有限预览产生超出检查范围的质量承诺，代价是工具必须保存最终所需文件与实际复核范围之间的对应关系。

静态图交付 SVG/PNG 时检查各实际图片及其展示条件，不再额外要求重复的时间线预览；仅交付 HTML 时检查实际文件的静态画面和初始暂停状态，动画任务还需检查关键状态、播放和必要的回看。所有必需检查完成且无未解决问题时质量才通过；缺少查看条件时保留未完成状态，用户明确接受的有意设计仍保留警告和决定。

请求文件已完整生成时，可以发布最终文件并保留质量缺口；任何请求文件未生成时，不替换上一份完整交付。这明确了 [ADR 0010](0010-final-diagram-files-by-default.md) 中发布失败与检查未完成的区别，默认仅保留最终文件的清理范围不变。
