# 新增几何风险诊断复用 SDK 的画面几何

Status: accepted

来源：FlowSVG [`86bb7ad`](https://github.com/yokingma/FlowSVG/blob/86bb7ad29484d7deb63142c1df84c6944a7c0eb4/docs/adr/0008-shared-sdk-geometry-diagnostics.md)。本仓保留与 Skill 有关的决策和职责边界。

本 ADR 是当前诊断集成决策记录；诊断字段、风险范围和限制以公开 SDK、skill reference、实现和测试为准。

连线穿过无关节点、标签与无关节点遮挡、标签之间遮挡的新增诊断由 SDK 复用求值和渲染所依据的几何计算，并通过公开结果供 skill 消费。skill 继续编排有限时间点的检查、汇总警告和记录用户决定，不复制内部路径解析或维护另一套文字尺寸估算。相比在 skill 中实现检测，这需要维护 SDK 的诊断合同，但可减少渲染与诊断不一致的风险；诊断仍是风险提示，不构成自动修复、连续覆盖或精确字体像素保证。

新增检测通过按需入口执行，不默认进入普通求值或播放循环，也不公开整套内部路径几何。节点检查使用实际形状轮廓，路径复用 SDK 几何与曲线采样，文字使用统一估算；这保留核心的确定性与平台边界，并避免每帧运行成对碰撞检查。

SDK 为单条风险提供包含参与对象、字段和文字位置的稳定 warningKey；工具结合源数据、SDK、时间与视觉选项登记 issueId。新用户决定精确引用源版本和 issueId，保留原警告及上下文；不按 code + objectId 将一个例外扩展到同一节点的其他对象、字段或时间。历史无标识记录原样保存，新决定通过新诊断版本取得精确引用。
