# 导出清单独立于图解文档

Status: accepted

来源：FlowSVG [`86bb7ad`](https://github.com/yokingma/FlowSVG/blob/86bb7ad29484d7deb63142c1df84c6944a7c0eb4/docs/adr/0007-export-manifest-outside-document.md)。本仓保留与 Skill 有关的决策和职责边界。

本 ADR 是当前静态交付决策记录；清单字段和校验规则以 skill reference、公开 SDK 和测试为准。

用于静态交付的命名画面由创作工具的独立导出清单管理，每个画面选定名称和时间点，单帧求值与导出仍使用公开 SDK。导出清单不向图解文档或节拍模型增加关键帧，也不改变所选时间点的显隐和镜头。相比将交付命名写入核心时间线，这使同一份图解能按不同用途组织交付，并避免静态导出要求改变动画语义；代价是清单与图解快照需要分别保存和核对。

清单同时绑定源 JSON 的字节哈希与实际 SDK 的版本和完整性标识。图解字节或 SDK 基线变化后需重新读取编译节拍、确认画面并形成新清单；即使源数据未变、旧时间点仍合法，也不能自动重用。同版本不同安装产物同样视为基线变化，因为路径算法变化可能改变单流时长。代价是仅格式变化或 SDK 升级也需要重建绑定。
